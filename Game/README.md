# 🎮 Project Kingdom — Web Prototype v1.0

ไฟล์เกมหลัก: [`index.html`](file:///G:/ไดรฟ์ของฉัน/SecondBrain/Second%20Brain/04_PROJECTS/Kingdom/Game/index.html)

## 📌 วิธีเล่น
ดับเบิ้ลคลิกเปิดไฟล์ `index.html` บน Google Chrome, Microsoft Edge, หรือเบราว์เซอร์ใดก็ได้ สามารถเล่นได้ทันทีโดยไม่ต้องติดตั้งโปรแกรมเสริม

## 🕹️ ปุ่มลัดและการควบคุม
- **คลิกซ้าย:** วางสิ่งปลูกสร้าง, เลือกอาคารเพื่อมอบหมายคนงาน (Worker Assignment), เลือกเทคโนโลยี, เจรจาการทูต
- **คลิกขวา / ESC:** ยกเลิกการสร้าง / ปิด Modal
- **ลากเมาส์ (Drag):** เลื่อนแผนที่ (Pan Camera)
- **F1 / ปุ่ม Dashboard:** เปิดดูกราฟเศรษฐกิจ, คลังสินค้า, และรายงานกำลังรบ AI
- **ปุ่ม Diplomacy:** ส่งของขวัญเพิ่มความสัมพันธ์, ทำสัญญาการค้า, ประกาศสงคราม
- **ปุ่ม Tech Tree:** วิจัยเทคโนโลยีเพื่อเพิ่มประสิทธิภาพของเมือง
- **ปุ่ม Save:** บันทึกเกมลง LocalStorage
