# 👹 Orc — นักรบ

| | รายละเอียด |
|---|---|
| **ข้อดี #1** | ผลิตทหารเร็วกว่า 2x, Barracks Upkeep -20% |
| **ข้อดี #2** | Morale ทหารสูงมาก — War Totem แผ่ Morale +40% |
| **ข้อเสีย** | Reputation ติดลบกับทุกเผ่าตั้งแต่ต้น |
| **Forbidden** | ไม่สามารถลงนามสนธิสัญญาการค้าระยะยาว (> 1 ปีในเกม) |
| **Unique Building** | War Totem — Morale +40% รัศมี 5 Tile แต่กินอาหาร 2x |
| **Victory Bias** | Conquest Victory — ยึดครองดินแดน >60% ของแผนที่ |
| **วิธีคิด** | ชนะด้วยความเร็วและความกลัว |

## Roles ทั้งหมด (Character Sprite Sheet)
1. Farmer
2. Builder / Worker
3. Soldier / Guard
4. Raider / Warrior
5. Merchant
6. Commander / General
7. Blacksmith

## Mount Unit
🐗 **หมูป่า (Boar)** — Charge + Morale Damage สูง

## Unique Units (Exclusive, x2 — Combat Value จริง)

| Unit | Role | Combat Value |
|---|---|---|
| **Boar Rider** | ทหารม้า (หมูป่า) ชาร์จทำลาย Morale ศัตรู | ATK สูงมาก + Charge ทำ Morale Damage เพิ่ม 2x |
| **Warchief** | หน่วยแนวหน้าเพิ่ม Morale กองทัพรอบข้าง | ATK สูง + Aura Morale +20% รัศมี 3 Tile |

**Forbidden:** ❌ ทหารม้าหนักแบบ Human (ตาม Lore — Orc ไม่เลี้ยงม้า)

## เหตุผลเชิงออกแบบ
Orc ชนะด้วย "ความเร็วและความกลัว" — หน่วยพิเศษทั้งสองเน้น **ทำลาย Morale ศัตรู** (Boar Rider) และ **เสริม Morale ฝ่ายตัวเอง** (Warchief) ทำให้การรบของ Orc จบเร็วด้วยการพังขวัญกำลังใจฝ่ายตรงข้ามก่อนถึงจะรบยาว — สอดคล้องกับ Victory Bias แบบ Conquest
